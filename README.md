# WT-4 ASP.NET Core MVC — Coquette Library 🌸

## Репозиторий
https://github.com/Rina-666/wt-lab4-4mvc-valkovich

## Опубликованное приложение
https://wt-lab4-4mvc-valkovich.onrender.com

## Функциональность
- Каталог книг в стиле coquette core (розовый, кружева, ленты)
- Просмотр подробной информации
- Добавление новых книг (GET/POST)
- Редактирование книг
- Удаление книг
- Валидация форм через DataAnnotations
- Адаптивный дизайн

## Технологии
- ASP.NET Core MVC 8.0
- Bootstrap 5 + Bootstrap Icons
- Google Fonts (Dancing Script, Quicksand)
- Docker
- Render (Web Service)
